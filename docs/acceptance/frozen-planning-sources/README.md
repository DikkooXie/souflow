# 验证规划使用固定源码

在隔离工作台用已提交的 `src/entry.mts` 和一个缺失路径开始规划。已提交文件随后在工作区改写。页面「本轮参考资料」显示固定提交、已读文件摘要和未读取路径。各阶段收到的是同一提交的脱敏内容，测试在接口输出中只观察到清单和生成的样例正文。

[本轮资料截图](01-planning-sources.jpg)

用本机原生 GPT-6.2 Astra 调研会话，读入一个 8,063 字节的固定文件。实际回复逐字给出首部、中部和尾部的三个独立标记，未返回工作区替换内容。再用相同输入发起一条隔离澄清，提交测试选项后完成调研并回读三个标记。

对应 [#94](https://github.com/DikkooXie/souflow/issues/94)。首版真实自动建单和双机交付继续由 [#67](https://github.com/DikkooXie/souflow/issues/67) 验收。
